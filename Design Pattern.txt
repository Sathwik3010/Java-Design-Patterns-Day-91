Observer Design Pattern
=======================
Observer design pattern is a behavioural design pattern that establishes one-to-many dependency between Objects.
when the subject(Observable changes) its state.all observers are automatically notified.

 Purpose
--------
To maintain synchronization between related objects without tight coupling.


Subject does not need to know the Observer's implementation — only their interface.
 Real-Life Example
YouTube Channel (Subject) → uploads a new video
 Subscribers (Observers) → get notification automatically

Command Pattern
===============
the command pattern is a behavioural design pattern that converts a request into a standalone Objects contains all the information about action that needs to be performed.

real-world scenario
--------------------
television is a device that has receiver of action like 

turnOff();
turnOn();

remote control does not know the TV works internally. it only knows how to send commands when button are passed.

Flyweight Design Pattern
========================
flyweight design patter is a structural design pattern used to reduce memory usage by sharing common(intrinsic) data among multiple Objects.

instead of creatin new Object everytime , Objects share pre-existing data when possible.

there are two types of data :-
intrensic data(common property)
extrensic data(distinct property)

Concept Summary
Data Type
Meaning
Example
Intrinsic State
Shared (doesn’t change)

Tree location (x, y)

Example Scenario
A forest has thousands of trees.
 Creating thousands of objects with duplicate color, type, texture wastes memory.
 Instead → Share 1 TreeType (Flyweight) object for all trees of same type.

 One-Liner Definitions (Exam Point of View)
Intrinsic State: Shared, constant data stored inside the Flyweight object.
 Example: Pen color.
Extrinsic State: Context-specific data passed to the Flyweight when needed.
 Example: Student name while writing.

 Why separate them?
Because storing unique data inside every object causes memory waste.
 Flyweight allows thousands of similar objects to share common data.
